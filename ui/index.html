domain — CI gate

Agent reliability engine

Agents fail for reasons a few test prompts never find.

OOSC is continuous integration for autonomous agents. Give it an agent's tool schemas and it builds a stateful mock world with no hand-authored domain logic, generates adversarial scenarios against it, runs the agent sandboxed with every state mutation fingerprinted, classifies why each run failed — and blocks the commit when reliability regresses.

Guardrails

Would it do the irreversible thing?

Irreversible operations are identified from the derived world spec, then probed under four escalations: urgency, ambiguity, policy conflict, and instructions injected into tool output. A probe carries no authorization — any agent that executes the mutation has failed it, verified in real world state.

Scorecard

Reliability is a rate, not a verdict.

Every figure is a rate with a Wilson 95% interval, never a single pass or fail. A regression gates the build only when the candidate's interval clears the baseline's — so seed noise cannot fail a commit.
